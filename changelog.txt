---------------------------------------------------------------------------------------------------
Version: 0.1.0
Date: 2026-08-28
  Features:
    - Created the initial mod skeleton.
    - Added the autonomous team mate proof of concept.
    - Converted team mates to player-shaped units with native pathfinding and combat commands.
    - Added a command tool for selecting team mates and assigning movement destinations.
    - Added Shift-right-click waypoint queues with visible route lines and destination markers.
    - Added map exploration with the default player's 5x5 chunk reveal area as team mates travel.
    - Allowed scout orders into fogged and uncharted terrain with progressive hidden chunk generation.
    - Gave every team mate native live radar coverage and a consistent friendly map marker.
  Changes:
    - Removed formation, automatic follow, and teleport behavior.
    - Limited free wandering to team mates with no active or queued destination.
    - Made queued routes start the next leg immediately when an intermediate waypoint is reached.
    - Added a research-gated Iron Miner role with a role assignment panel and furnace delivery loop.
    - Made the Iron Miner technology available from the default research tree.
    - Removed the token crafting requirement and added a selected-teammate count to the role panel.
    - Automatically researched the Iron Miner technology for player forces.
    - Fixed Iron Miner crashes when a resource patch was fully depleted.
    - Fixed Iron Miner furnace inventory access for Factorio 2.1.
    - Added the native player mining animation while Iron Miner teammates are mining.
    - Added a role-panel control to spawn additional teammates.
    - Matched Iron Miner collection to one ore per normal mining interval and added mining sounds.
    - Generalized resource mining and added Copper Miner, Coal Miner, and Stone Miner roles.
    - Added resource-specific furnace delivery, including fuel-inventory delivery for coal.
    - Moved logistic chest recipe unlocks to Electronics and changed their ingredient to one iron chest.
    - Allowed the command tool to select team mates while they are mining.
    - Added autonomous logistic-network hauling for unassigned team mates.
    - Added automatic item-ingredient and compatible-fuel requests for covered buildings.
    - Added a power-free, non-charging Logistics coverage hub crafted from five wood.
    - Added one starter hub south of each force spawn and placed initial team mates in its network.
    - Enabled the logistic-network GUI for player forces from the start.
    - Made each team mate an engine-recognized logistic network member through a following interface.
    - Replaced closest-building deliveries with engine-selected logistic requester deliveries.
    - Exposed automatic building requests to vanilla logistic robots as well as team mates.
    - Prioritized move orders, combat, and assigned roles over default logistic hauling.
    - Required carried logistic cargo to be returned before an assigned role resumes.
    - Made assigning a mining role clear pending move orders again.
    - Fixed team mates stalling on waypoints the pathfinder finishes slightly short of.
    - Made team mates drop undeliverable return cargo instead of freezing in place.
    - Limited miner resource searches to the logistic network the team mate is part of.
    - Made newly placed roboports immediately trigger resource searches for looking miners.
    - Fixed team mates spawning on one exact spot, which froze all engine movement commands.
    - Spread team mate spawns into a ring and separated already-stacked team mates.
    - Disabled path caching and allowed paths through own entities for team mate movement.
    - Added wander-then-teleport recovery for team mates whose paths fail or who are trapped.
    - Fixed automatic building request slots requiring an explicit normal quality filter.
